## Known items carried into Phase 1

- `u64` fields export as TypeScript `bigint` — when implementing the control
  plane (ADR-002) we decide the JSON number strategy (number vs string ids)
  in one place, not scattered.
- `Body` is fully materialized in memory; streaming + disk spooling (ADR-003)
  land with the real proxy code path.
- `Headers` values are UTF-8 strings; latin-1/binary header values arrive with
  the wire parser (the ordered-list shape stays identical).
